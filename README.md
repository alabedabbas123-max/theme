# SwiftKeyIME

هذا المستودع يحتوي على مشروع **لوحة الملك** المستخرج والمنظّف من `SwiftKeyIME.zip` الموجود في المستودع الأصلي.

## بنية المشروع

- `SwiftKeyIME/` — مشروع Android/Gradle الفعلي.
- `SwiftKeyIME/app/src/main/` — كود Java والموارد والقواميس والأصول.
- `SwiftKeyIME/tests/` — اختبارات العقود الثابتة للمشروع.
- `SwiftKeyIME/tools/` — أدوات التدقيق التي يحتاجها فريق التطوير.

## ما تم تنظيفه وتحسينه

- إزالة نواتج البناء (`app/build`) والملفات المؤقتة وملف `local.properties` الذي قد يحتوي على أسرار محلية.
- إزالة ملفات التسليم/الجرد الداخلية المولّدة والملف المضغوط المكرر؛ مصدر المشروع الآن موجود مباشرة داخل `SwiftKeyIME/`.
- تحويل الصور الفوتوغرافية من JPEG إلى WebP مع الحفاظ على أسماء موارد Android نفسها، حتى تبقى مراجع Java و`R.drawable` مستقرة.
- تحسين ضغط صور PNG دون فقدان (إزالة البيانات الوصفية ورفع كفاءة الضغط) مع إبقاء PNG الشفافة كما هي؛ هذا يحافظ على الحواف والألفا والتوافق مع الحد الأدنى المعلن للتطبيق.
- تحويل صورة الهوية التسويقية إلى WebP lossless.
- عدم تغيير أبعاد الصور أو ألوان البكسلات أثناء التحسين؛ ملفات المفاتيح الشفافة وواجهات المستخدم بقيت PNG حفاظًا على الجودة وسرعة فكّها.

## التشغيل والبناء

1. افتح مجلد `SwiftKeyIME` في Android Studio أو AIDE كمشروع Gradle.
2. انسخ `SwiftKeyIME/local.properties.example` إلى `SwiftKeyIME/local.properties` فقط عند الحاجة، ثم أضف القيمة المحلية الخاصة بك لـ `THEMATY_GITHUB_TOKEN`. لا تضع أسرارًا في Git.
3. ينفذ البناء وفق إعدادات `SwiftKeyIME/app/build.gradle` الحالية (`compileSdkVersion 30` و`minSdkVersion 16`).
4. لا توجد APK أو ملفات build داخل المستودع؛ يتم توليدها محليًا عند البناء.

## الاختبارات

من داخل مجلد المشروع:

```bash
cd SwiftKeyIME
python3 -m unittest discover -s tests -q
```

بعض اختبارات الصور الاختيارية تحتاج Pillow، كما أن بناء Android الكامل يحتاج Android SDK وGradle/Android Studio.
